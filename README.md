# Rotave Wellness API

NestJS + MongoDB backend for Rotave Wellness.

## Quick start

```bash
# From project root — start MongoDB
docker compose up -d

# Backend
cd back_end
cp .env.example .env   # if needed
npm install
npm run start:dev
```

API: http://localhost:4000

Default superadmin: `kjoeldewan@gmail.com` / `RotaveAdmin2026!` (from env)
